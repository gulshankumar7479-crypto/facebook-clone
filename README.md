# Facebook Clone
Hello I am "Gulshan Kumar Verma.
I am creating a **Facebook Clone** as a learning project to improve my web development skills, especially my understanding of **HTML and CSS**.

The main goal of this project is to recreate the basic layout and user interface of Facebook while learning how modern websites are designed and structured.

During this project, I am practicing different CSS concepts such as:

* Creating responsive layouts
* Using Flexbox and CSS Grid
* Designing navigation bars
* Creating profile and post sections
* Styling buttons, icons, and forms
* Working with colors, fonts, spacing, margins, and padding
* Creating cards and containers
* Understanding positioning and alignment
* Making the webpage responsive for different screen sizes
* Organizing CSS code in a clean and reusable way

This project is mainly focused on **learning and practice**, rather than creating an exact copy of Facebook. As I continue learning JavaScript and backend development, I plan to add more interactive features such as posting, liking, commenting, login/signup, and user profiles.

### Technologies Used

* HTML5
* CSS3
* JavaScript *(planned)*
* Python/FastAPI *(planned for backend)*

### Learning Objective

Through this project, I want to strengthen my fundamentals of **frontend development** and understand how real-world social media interfaces are structured. It will also help me practice writing clean HTML, CSS, and eventually JavaScript code.

This project is being developed step-by-step as part of my journey to become a **web developer**.
